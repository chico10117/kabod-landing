# Kabod Hair Frontend Prototype

Frontend-only React prototype for Kabod Hair, built with Vite, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The build outputs `dist/index.html`, `dist/404.html`, and `.nojekyll` so it can run as a single-page app on GitHub Pages.

## GitHub Pages

Deployments are handled by `.github/workflows/deploy-pages.yml` on pushes to `main`.
